# 颯エンタープライズ 建設事業部 工事管理 デモ用Webアプリ

HTMLモック `hayate_mock_v0.1.5.html` を Next.js（App Router）＋ TypeScript に移植したデモ用アプリです。
データはすべて架空のサンプルで、ブラウザ内の状態（React Context）だけで動きます。DB・ログイン・外部APIは使いません。リロードすると初期状態に戻ります。

## 起動方法

```bash
npm install
npm run dev        # 開発サーバー http://localhost:3000
```

静的書き出し（`next.config.ts` の `output: 'export'`）：

```bash
npm run build      # out/ に静的ファイルを書き出す
npx serve out      # 書き出したものを確認（任意）
```

## 使い方（デモの流れ）

画面上部の「デモの流れ」ボタンで ⓪〜⑥ の順に操作できます。右上で「表示（PC／スマホ）」と「表示中の役割」を切り替えます。

1. ① 見積を作る（S-03）→ ② 受注確定（S-02 の「受注する」）→ 工事番号を採番し、見積の原価から実行予算の下書きを作る
2. ③ 打刻（スマホ M-02 / 共用端末 T-01）→ ④ 日次チェック・承認（S-06）→ 承認・確認した人工だけが
3. ⑤ 工事台帳（S-05）の労務費と、⑥ 外注支払（S-08）に反映される

「初期状態に戻す」でサンプルデータに戻ります。

## 構成

```
app/                 画面（App Router。1画面＝1ディレクトリ）
  layout.tsx         共通レイアウト（StoreProvider・ヘッダー・メニュー）
  globals.css        HTMLモックのCSSとトークンCSSをそのまま
components/          共通部品（shell, ui, filter, svgs, 各画面の部品）
lib/
  types.ts           型
  data.ts            サンプルデータ（型付き）
  calc.ts            計算（見積・実行予算・人工・原価・外注支払）。純関数
  store.ts           データの読み書き（ここだけ。将来DBに差し替える）
  store-context.tsx  React Context（ブラウザ内の状態・トースト）
public/logo.png      ロゴ
```

## 業務ルール（設計書より）

- 工事番号で見積→受注→実行予算→打刻→原価→支払をつなぐ
- 受注確定で工事番号を採番し、見積から実行予算の下書きを作る
- 労務費は承認（社員）・確認（外部）済みの人工からだけ自動計上する
- 外部作業員は「承認」ではなく「確認（検収）」。勤怠集計には入れず、外注支払にだけ出す
- 勤怠集計は社員のみ。給与計算はしない
- 費目は 材料費／労務費（うち労務外注費）／外注費／経費。予測（着地見込み）は作らない
