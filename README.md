# 颯エンタープライズ 建設事業部 工事管理（モックアプリ）

HTMLモック `hayate_mock_v1.1.html` をもとにした、動くモックアプリです（Next.js App Router ＋ TypeScript、静的書き出し）。
データはすべて架空のサンプルで、入力した内容はブラウザ（localStorage）に保存されます。DB・外部APIは使いません。

## 起動方法

```bash
npm install
npm run dev        # 開発サーバー http://localhost:3000
```

静的書き出し（`next.config.ts` の `output: 'export'`）：

```bash
npm run build      # out/ に静的ファイルを書き出す
npx serve out      # 書き出したものを確認（任意）
```

## 使い方

1. ログイン画面でユーザーを選んでログインします（パスワードは検証しません）。役割はユーザーで決まります
   - 川口（管理者）、望月（経理）、佐藤・田中（職長）、鈴木ほか（社員職人）、渡辺ほか（協力会社）
2. 事務所の役割（管理者・経理・職長）は左メニューの画面、作業員（社員職人・協力会社）はスマホ画面（打刻）になります。職長はメニューの「打刻（自分のスマホ）」からスマホ画面にも入れます
3. 「今日」は実際の日付です。サンプルデータは今日を基準に日付を合わせてあります。打刻は押した時刻で記録されます
4. 入力した内容はブラウザに保存され、リロードしても残ります。サンプルに戻すには「会社設定」の「データを初期化」を使います

### 業務の流れ

見積（S-03）→ 与件詳細で受注（S-04：工事番号を採番、実行予算の下書き）→ 打刻（M-02 / T-01）→ 日次チェックで承認・確認（S-06）→ 工事台帳の労務費（S-05）と外注支払（S-08）に反映 → 勤怠集計（S-07）

## 労務費の計算（モック v1.1）

- 社員の実績の労務費は会社設定の方式で計算します。B（賃金相当）＝打刻から1日ごとに賃金相当額（基本＋時間外25%〈月60時間超50%〉＋深夜25%＋法定休日35%）×（1＋会社負担率＋賞与引当率）を計算し、現場ごとの実働の比率で按分。A（標準単価）＝人工（実働÷所定時間）×標準単価
- 外部作業員は今までどおり 0.25人工に丸めた人工×協力会社の常用単価（外注支払と同じ）
- 就業ルールは版（適用開始日）で持ち、社員の紐付けは履歴で持ちます。過去の月は当時のルールで計算します
- 実行予算は「見積の原価＋調整（確定前）」を当初予算として固定し、確定後は「変更」の明細を理由区分つきで1件ずつ積みます

## 業務ルール（設計書より）

- 工事番号で見積→受注→実行予算→打刻→原価→支払をつなぐ
- 受注確定で工事番号を採番し、見積から実行予算の下書きを作る
- 労務費は承認（社員）・確認（外部）済みの人工からだけ自動計上する
- 外部作業員は「承認」ではなく「確認（検収）」。勤怠集計には入れず、外注支払にだけ出す
- 勤怠集計は社員のみ。給与計算はしない
- 費目は 材料費／労務費（うち労務外注費）／外注費／経費。予測（着地見込み）は作らない
